# Project Instructions

## Superpowers & Workflow
This project is configured with the **Superpowers** and **Anti-Slop** skill suites.
- When beginning a new feature or major task, use `brainstorming` and `writing-plans`.
- Follow Red/Green/Refactor TDD using `test-driven-development` where applicable.
- Adhere to `systematic-debugging` for bug fixes.
- Before completion, run `verification-before-completion`.

## Anti-Slop Quality Gate
- Adhere strictly to **antislop** rules (R-01 to R-38) across UI (`antislop-ui`), copywriting (`antislop-copywriting`), and responsive layout (`antislop-layoutmobile`).
- Avoid generic AI patterns (muddy dark modes, badge salad, loose numbers, robotic copy).
- Strive for Linear / Raycast / Vercel design engineering standards.
